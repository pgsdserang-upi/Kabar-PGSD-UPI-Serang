# Folder Gambar

Simpan semua foto/gambar berita di folder ini.

Cara memakainya di berita:

- Sebagai gambar utama (muncul di atas berita): tambahkan baris ini di bagian atas berkas berita, di antara dua garis `---`:

      gambar: "/gambar/nama-foto-anda.jpg"

- Di tengah isi berita: sisipkan baris berikut pada isi berita:

      ![Keterangan singkat foto](/gambar/nama-foto-anda.jpg)

Tips:
- Gunakan nama berkas huruf kecil tanpa spasi (pakai tanda minus), contoh: `seminar-nasional-2026.jpg`.
- Ukuran wajar (lebar 1200–1600 px) agar situs tidak berat.
